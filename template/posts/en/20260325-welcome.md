**pypost** is a minimal blog framework built on [FastHTML](https://fastht.ml), [Mistune](https://mistune.lepture.com), and [Pygments](https://pygments.org). No build step, no database — just Markdown files and Python.

## How it works

Posts are plain `.md` files with YAML frontmatter. Drop a file into `posts/en/` or `posts/es/` and it appears on the blog immediately after a server restart.

```
posts/
├── en/
│   └── my-post.md
└── es/
    └── mi-articulo.md
```

## Frontmatter fields

| Field | Required | Description |
|---|---|---|
| `title` | yes | Post title |
| `date` | yes | Publication date (`YYYY-MM-DD`) |
| `published` | yes | Set to `true` to make visible |
| `slug` | no | URL slug (auto-derived from title) |
| `description` | no | Shown on cards and RSS |
| `tags` | no | List of tags |
| `series` | no | Series name for multi-part posts |
| `series_part` | no | Part number within the series |
| `toc` | no | Set to `false` to disable auto-ToC |
